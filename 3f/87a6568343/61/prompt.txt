# Architecture Reorganization Plan: specd as UDA/f Core Engine

## Context

### Why This Change Is Needed

The current architecture has a fundamental misalignment with the project's vision as described in CLAUDE.md:

> **specORACLE is a reverse mapping engine.**
> It constructs U0 (the root specification) from diverse artifacts through reverse mappings.

Currently:
- **specd** is minimal (43 lines), merely wrapping a FileStore with gRPC
- **spec-cli** has Standalone mode that directly manipulates files, bypassing specd
- **gRPC schema** exposes low-level node/edge operations, not UDA/f model concepts
- **No project/namespace support** - everything in a single global graph

This violates the intended docker/dockerd relationship where specd should be the authoritative core engine managing the formal world based on the UDA/f model.

### What We're Building

A clean separation of concerns following the UDA/f theoretical model:

```
spec-cli (Natural Language World)
    ↓ gRPC (UDA/f operations)
specd (Formal World - UDA/f Model Manager)
    ↓ Local filesystem
Projects in ~/.specd/projects/
```

**specd becomes:**
- Core engine managing UDA/f model (Universe, Domain, AdmissibleSet, Transform, Projection)
- Project/namespace manager (like docker contexts)
- Verification executor (Z3-backed formal proofs)
- Reverse mapping engine (construct U0 from artifacts)
- **Pluggable storage backend** (filesystem, database, S3, Git - decided per project)

**spec-cli becomes:**
- Pure intermediary translating user intent to specd operations
- No direct file access
- Future: LLM/AI Agent integration for natural language formalization

```rust
#[derive(Debug, Clone)]
pub struct ProjectConfig {
    pub name: String,
    pub description: String,
    pub created_at: i64,
    pub storage: StorageConfig,
}

impl ProjectConfig {
    pub fn load(path: &Path) -> Result<Self> {
        let conf = Ini::load_from_file(path)?;

        let project_section = conf.section(Some("project"))
            .ok_or_else(|| anyhow!("Missing [project] section"))?;
        let storage_section = conf.section(Some("storage"))
            .ok_or_else(|| anyhow!("Missing [storage] section"))?;

        let storage = match storage_section.get("backend").unwrap_or("local") {
            "local" => StorageConfig::LocalFile {
                base_path: PathBuf::from(storage_section.get("path").unwrap_or(".")),
            },
            "postgres" | "postgresql" => StorageConfig::Database {
                connection_string: storage_section.get("connection_string")
                    .ok_or_else(|| anyhow!("Missing connection_string"))?.to_string(),
                schema: storage_section.get("schema").map(|s| s.to_string()),
            },
            "s3" => StorageConfig::S3 {
                bucket: storage_section.get("bucket")
                    .ok_or_else(|| anyhow!("Missing bucket"))?.to_string(),
                prefix: storage_section.get("prefix").unwrap_or("").to_string(),
                region: storage_section.get("region")
                    .ok_or_else(|| anyhow!("Missing region"))?.to_string(),
            },
            _ => return Err(anyhow!("Unknown storage backend")),
        };

        Ok(Self {
            name: project_section.get("name")
                .ok_or_else(|| anyhow!("Missing name"))?.to_string(),
            description: project_section.get("description").unwrap_or("").to_string(),
            created_at: project_section.get("created_at")
                .and_then(|s| s.parse::<i64>().ok())
                .unwrap_or(0),
            storage,
        })
    }

    pub fn save(&self, path: &Path) -> Result<()> {
        let mut conf = Ini::new();

        conf.with_section(Some("project"))
            .set("name", &self.name)
            .set("description", &self.description)
            .set("created_at", &self.created_at.to_string());

        let storage_section = conf.with_section(Some("storage"));
        match &self.storage {
            StorageConfig::LocalFile { base_path } => {
                storage_section.set("backend", "local");
                storage_section.set("path", base_path.display().to_string());
            }
            StorageConfig::Database { connection_string, schema } => {
                storage_section.set("backend", "postgres");
                storage_section.set("connection_string", connection_string);
                if let Some(s) = schema {
                    storage_section.set("schema", s);
                }
            }
            StorageConfig::S3 { bucket, prefix, region } => {
                storage_section.set("backend", "s3");
                storage_section.set("bucket", bucket);
                storage_section.set("prefix", prefix);
                storage_section.set("region", region);
            }
            _ => {}
        }

        conf.write_to_file(path)?;
        Ok(())
    }
}
```

```rust
/// Storage backend trait - projects can choose where/how to store data
pub trait StorageBackend: Send + Sync {
    fn save_udaf_model(&self, project: &str, model: &UDAFModel) -> Result<()>;
    fn load_udaf_model(&self, project: &str) -> Result<UDAFModel>;
    fn save_repository(&self, project: &str, repo: &SpecRepository) -> Result<()>;
    fn load_repository(&self, project: &str) -> Result<SpecRepository>;
    fn delete_project(&self, project: &str) -> Result<()>;
    fn exists(&self, project: &str) -> bool;
}

/// Storage backend configuration (serializable)
#[derive(Serialize, Deserialize, Clone)]
pub enum StorageConfig {
    LocalFile {
        base_path: PathBuf,
    },
    Database {
        connection_string: String,
        schema: Option<String>,

    S3 {
        bucket: String,
        prefix: String,
        region: String,
    },
    Git {
        repo_url: String,
        branch: String,
        path_prefix: String,
    },
}

impl StorageConfig {
```

```rust
pub struct LocalFileBackend {
    base_path: PathBuf,
}

impl StorageBackend for LocalFileBackend {
    fn save_udaf_model(&self, project: &str, model: &UDAFModel) -> Result<()> {
        let project_path = self.base_path.join(project);
        fs::create_dir_all(&project_path)?;

        let model_json = serde_json::to_string_pretty(model)?;
        fs::write(project_path.join("udaf-model.json"), model_json)?;
        Ok(())
    }

    fn load_udaf_model(&self, project: &str) -> Result<UDAFModel> {
        let model_json = fs::read_to_string(
            self.base_path.join(project).join("udaf-model.json")
        )?;
        Ok(serde_json::from_str(&model_json)?)
    }

    fn save_repository(&self, project: &str, repo: &SpecRepository) -> Result<()> {
        let project_path = self.base_path.join(project);
        let store = DirectoryStore::new(&project_path);
        store.save(repo)
    }

    fn load_repository(&self, project: &str) -> Result<SpecRepository> {
        let project_path = self.base_path.join(project);
        let store = DirectoryStore::new(&project_path);
        store.load()
    }

    fn delete_project(&self, project: &str) -> Result<()> {
        fs::remove_dir_all(self.base_path.join(project))?;
        Ok(())
    }

    fn exists(&self, project: &str) -> bool {
        self.base_path.join(project).exists()
    }
}
```

**Quality: Why This Design?**
- **Separation of Concerns**: Storage logic isolated from business logic
- **Future-Proof**: Easy to add Database/S3/Git backends without touching ProjectManager
- **Testability**: Mock storage backend for unit tests
- **Type Safety**: Trait enforces consistent interface
- **Error Handling**: All operations return Result, failures are explicit

#### 1.2 Create Project Management Module

**New File:** `specd/src/project.rs`

```rust
pub struct ProjectManager {
    projects: HashMap<String, ProjectHandle>,
    current_project: Option<String>,
    storage_configs: HashMap<String, StorageConfig>,
}

pub struct ProjectHandle {
    name: String,
    description: String,
    created_at: i64,
    storage_backend: Box<dyn StorageBackend>,
}

pub struct Project {
    name: String,
    description: String,
    created_at: i64,
    udaf_model: UDAFModel,
    repository: SpecRepository,
}

impl ProjectManager {
    pub fn new() -> Self {
        Self {
            projects: HashMap::new(),
            current_project: None,
            storage_configs: HashMap::new(),
        }
    }

    /// Create project with specified storage backend
    pub fn create_project(
        &mut self,
        name: String,
        desc: String,
        storage: StorageConfig,
    ) -> Result<()> {
        let backend = storage.create_backend()?;

        // Initialize project data
        let udaf_model = UDAFModel::new();  // Creates U0
        let repository = SpecRepository::new();

        // Save to storage
        backend.save_udaf_model(&name, &udaf_model)?;
        backend.save_repository(&name, &repository)?;

        // Register project
        self.projects.insert(name.clone(), ProjectHandle {
            name: name.clone(),
            description: desc,
            created_at: chrono::Utc::now().timestamp(),
            storage_backend: backend,
        });
        self.storage_configs.insert(name.clone(), storage);

        Ok(())
    }

    /// Load project from storage
    pub fn load_project(&mut self, name: &str) -> Result<Project> {
        let handle = self.projects.get(name)
            .ok_or_else(|| anyhow!("Project not found: {}", name))?;

        Ok(Project {
            name: handle.name.clone(),
            description: handle.description.clone(),
            created_at: handle.created_at,
            udaf_model: handle.storage_backend.load_udaf_model(name)?,
            repository: handle.storage_backend.load_repository(name)?,
        })
    }

    /// Save project to storage
    pub fn save_project(&self, project: &Project) -> Result<()> {
        let handle = self.projects.get(&project.name)
            .ok_or_else(|| anyhow!("Project not found: {}", project.name))?;

        handle.storage_backend.save_udaf_model(&project.name, &project.udaf_model)?;
        handle.storage_backend.save_repository(&project.name, &project.repository)?;
        Ok(())
    }

    pub fn switch_project(&mut self, name: &str) -> Result<()> {
        if !self.projects.contains_key(name) {
            return Err(anyhow!("Project not found: {}", name));
        }
        self.current_project = Some(name.to_string());
        Ok(())
    }

    pub fn list_projects(&self) -> Vec<ProjectInfo> {
        self.projects.values()
            .map(|h| ProjectInfo {
                name: h.name.clone(),
                description: h.description.clone(),
                created_at: h.created_at,
                storage: self.storage_configs.get(&h.name).cloned(),
            })
            .collect()
    }

    pub fn delete_project(&mut self, name: &str) -> Result<()> {
        let handle = self.projects.remove(name)
            .ok_or_else(|| anyhow!("Project not found: {}", name))?;

        handle.storage_backend.delete_project(name)?;
        self.storage_configs.remove(name);

        if self.current_project.as_deref() == Some(name) {
            self.current_project = None;
        }

        Ok(())
    }
}
```

```rust
pub fn import_legacy_spec_directory(
    spec_dir: &Path,
    project_name: String,
    project_manager: &mut ProjectManager,
) -> Result<ImportReport, String> {
    // 1. Load SpecRepository from .spec/
    let store = detect_store(spec_dir)?;
    let repository = store.load()?;

    // 2. Synthesize UDAFModel from SpecRepository
    let mut udaf_model = UDAFModel::new();  // Creates U0

    // Create projection universes from formality_layer metadata
    let mut layers_seen = HashSet::new();
    for node in repository.nodes() {
        if node.formality_layer > 0 && !layers_seen.contains(&node.formality_layer) {
            udaf_model.add_universe(
                node.formality_layer,
                format!("U{}", node.formality_layer),
                format!("Layer {} specifications", node.formality_layer),
            )?;
            layers_seen.insert(node.formality_layer);
        }
    }

    // Use ModelSync to populate UDAFModel from SpecRepository
    ModelSync::sync_from_repository(&mut udaf_model, &repository)?;

    // 3. Create project with synthesized model
    let mut project = Project {
        name: project_name.clone(),
        description: format!("Imported from {}", spec_dir.display()),
        created_at: chrono::Utc::now().timestamp(),
        udaf_model,
        repository,
    };

    // 4. Save to specd storage
    project.save(project_manager.base_path())?;
    project_manager.add_project(project);

    Ok(ImportReport {
        nodes_imported: repository.node_count(),
        edges_imported: repository.edge_count(),
    })
}

fn detect_store(spec_dir: &Path) -> Result<Box<dyn Store>, String> {
    // Priority 1: Directory-based (.spec/nodes/)
    if spec_dir.join("nodes").exists() {
        Ok(Box::new(DirectoryStore::new(spec_dir)))
    }
    // Priority 2: File-based (.spec/specs.json)
    else if spec_dir.join("specs.json").exists() {
        Ok(Box::new(FileStore::new(&spec_dir.join("specs.json"))))
    }
    else {
        Err("No valid spec storage found".to_string())
    }
}
```

### Phase 5: Quality Assurance & Documentation

**Goal:** Production-ready architecture with comprehensive testing and failure scenario coverage

#### 5.1 Quality Strategy

**Error Handling:**
- All public APIs return `Result<T, E>` - no unwrap() in library code
- Errors are structured with context: `anyhow::Context` for operations
- gRPC errors map to tonic::Status with appropriate codes:
  - `NOT_FOUND` for missing projects/nodes
  - `ALREADY_EXISTS` for duplicate projects
  - `INVALID_ARGUMENT` for bad requests
  - `UNAVAILABLE` for storage backend failures
  - `INTERNAL` for unexpected errors (with sanitized messages)

**Type Safety:**
- Newtypes for identifiers: `ProjectId`, `UniverseId`, `DomainId`
  - Prevents mixing up IDs across types
  - Example: `ProjectId(String)` vs `UniverseId(String)`
- Enum exhaustiveness: `#[non_exhaustive]` for proto enums to prevent breaking changes
- Builder pattern for complex requests (e.g., `CreateProjectRequest::builder()`)

**Concurrency Safety:**
- All shared state wrapped in `Arc<RwLock<T>>` or `Arc<Mutex<T>>`
- No global mutable state
- Storage backends must implement `Send + Sync`
- Lock ordering documented to prevent deadlocks:
  1. ProjectManager locks
  2. Project-specific locks
  3. Storage backend locks
