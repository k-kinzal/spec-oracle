# Plan: Separate Projection (f) from Extractor in Formal Layer

## Context

**Problem**: The current formal layer mixes projection functions and extractors, violating the paper model.

According to `/Users/ab/Projects/spec-oracle/paper/manuscript/uadf_u0_spec_proof.md` §2.6, the model requires clear separation:

```
proj_i : Ω → Option β_i  (projection from root to layer)
  = (obs_i : Ω → Option Γ_i) >> (extract_i : Γ_i → Option β_i)
```

Where:
- **Ω**: Root space (behavioral trace or artifact bundle)
- **Γ_i**: Artifact space (requirements docs, API specs, code)
- **β_i**: Layer-specific IR (intermediate representation)
- **obs_i**: Observer (root → artifact)
- **extract_i**: Extractor (artifact → IR)
- **proj_i**: Projection composition

**Current Reality** (from exploration):
- `TransformStrategy::ASTAnalysis` conflates projection and extraction
- No explicit Ω (root space) type
- No Γ_i (artifact space) type
- `execute_transform()` directly calls `RustExtractor::extract()`
- Projection and extraction are mixed together

**User Requirement**: Make formal layer types correct according to paper model. Defer implementation details of U0 construction.

```rust
        let meta = self.meta.as_ref().ok_or("No metadata")?;
        let content_type = meta.content_type().ok_or("No content type")?;
        let content_value = meta.content_value().ok_or("No content value")?;

        match content_type.as_str() {
            "text" => Ok(content_value.clone()),

            "structured" => Ok(content_value.clone()),
            _ => Err(format!("Unknown content type: {}", content_type)),
```

```rust
use crate::formal::projection::{RootSpace, RootSpaceKind, ArtifactSpace, ArtifactKind};
use crate::formal::universe::UniverseId;

/// Observer: obs_i: Ω → Option Γ_i
pub trait Observer: Send + Sync {
    fn observe(&self, root: &RootSpace, layer_id: &UniverseId) -> Option<ArtifactSpace>;
    fn artifact_kind(&self) -> ArtifactKind;
}

/// Artifact bundle observer (default for PoC)
/// Observes artifacts from an artifact bundle root space
pub struct ArtifactBundleObserver;

impl Observer for ArtifactBundleObserver {
    fn observe(&self, root: &RootSpace, layer_id: &UniverseId) -> Option<ArtifactSpace> {
        let meta = root.meta.as_ref()?;

        // Check that this is an artifact bundle
        if meta.kind()? != RootSpaceKind::ArtifactBundle {
            return None;
        }

        let layer_name = layer_id.as_str();

        // Get artifact path from metadata
        // Format: "artifact_{layer_name}_path"
        let artifact_key = format!("artifact_{}_path", layer_name);
        let artifact_path = meta.get(&artifact_key)?;

        // Create artifact space from file reference
        Some(ArtifactSpace::from_file(
            PathBuf::from(artifact_path),
            self.artifact_kind(),
        ))
    }

    fn artifact_kind(&self) -> ArtifactKind {
        ArtifactKind::SourceCode
    }
}

/// Trace observer (for Ω_trace)
/// Observes events from a behavioral trace root space
pub struct TraceObserver {
    pub layer_name: String,
}

impl Observer for TraceObserver {
    fn observe(&self, root: &RootSpace, _layer_id: &UniverseId) -> Option<ArtifactSpace> {
        let meta = root.meta.as_ref()?;

        // Check that this is a trace
        if meta.kind()? != RootSpaceKind::Trace {
            return None;
        }

        // Get trace events from metadata
        // Format: "trace_events" contains JSON array of events
        let events_json = meta.get("trace_events")?;
        let all_events: Vec<serde_json::Value> = serde_json::from_str(events_json).ok()?;

        // Filter events for this layer
        let layer_events: Vec<_> = all_events
            .into_iter()
            .filter(|event| {
                event.get("layer")
                    .and_then(|l| l.as_str())
                    .map(|l| l == self.layer_name)
                    .unwrap_or(false)
            })
            .collect();

        if layer_events.is_empty() {
            return None;
        }

        // Create artifact space from structured data
        let event_data = serde_json::to_value(layer_events).ok()?;
        Some(ArtifactSpace::from_structured(
            event_data,
            ArtifactKind::TestCode,
            format!("trace:{}", self.layer_name),
        ))
    }

    fn artifact_kind(&self) -> ArtifactKind {
        ArtifactKind::TestCode
    }
}

/// File system observer
/// Observes artifacts directly from file system
pub struct FileSystemObserver {
    pub base_path: PathBuf,
}

impl Observer for FileSystemObserver {
    fn observe(&self, _root: &RootSpace, layer_id: &UniverseId) -> Option<ArtifactSpace> {
        // Map layer to file pattern
        let pattern = match layer_id.layer() {
            1 => "**/*.tla", // Formal specs
            2 => "**/*.proto", // API specs
            3 => "**/*.rs", // Source code
            _ => return None,
        };

        // Find first matching file
        // (In real implementation, would use glob and select appropriately)
        let file_path = self.base_path.join(pattern);

        Some(ArtifactSpace::from_file(
            file_path,
            self.artifact_kind(),
        ))
    }

    fn artifact_kind(&self) -> ArtifactKind {
        ArtifactKind::SourceCode
    }
}
```

**projection/projection.rs**

Define proj_i composition and Extractor trait:

```rust
/// Extractor trait: extract_i: Γ_i → Option β_i
pub trait Extractor<T>: Send + Sync {
    fn extract(&self, artifact: &ArtifactSpace) -> Result<Vec<T>, String>;
}

/// Projection: proj_i = obs_i >> extract_i
pub struct Projection<O, E> {
    pub observer: O,
    pub extractor: E,
    pub target_layer: UniverseId,
}

impl<O, E, T> Projection<O, E>
where
    O: Observer,
    E: Extractor<T>,
{
    /// Execute projection: obs >> extract
    pub fn project(&self, root: &RootSpace) -> Result<Vec<T>, String> {
        // Step 1: obs_i(root) → Option Γ_i
        let artifact = self.observer.observe(root, &self.target_layer)
            .ok_or_else(|| format!("No artifact for layer {}", self.target_layer.as_str()))?;

        // Step 2: extract_i(artifact) → Option β_i
        self.extractor.extract(&artifact)
    }
}
```

```rust
impl UDAFModel {
    fn execute_transform(
        &self,
        transform: &TransformFunction,
        graph: &SpecRepository,
        root: &RootSpace,  // NEW: explicit root space
    ) -> Result<Vec<InferredSpecification>, String> {
        match &transform.strategy {
            ProjectionStrategy::ASTExtraction { language, observer, extractor_config } => {
                if language == "rust" {
                    self.execute_rust_projection(observer, extractor_config, root)
                } else {
                    Err(format!("Unsupported language: {}", language))
                }
            }
            ProjectionStrategy::Manual { .. } => Ok(Vec::new()),
            _ => Ok(Vec::new()),
        }
    }

    fn execute_rust_projection(
        &self,
        observer_kind: &ObserverKind,
        config: &HashMap<String, String>,
        root: &RootSpace,
    ) -> Result<Vec<InferredSpecification>, String> {
        // Instantiate observer and extractor
        let observer = observer_kind.instantiate();
        let extractor = RustExtractor;

        // Create projection
        let projection = Projection {
            observer,
            extractor,
            target_layer: UniverseId::projection(3, "code".to_string(), String::new())?,
        };

        // Execute: obs >> extract
        let specs = projection.project(root)?;

        // Filter by confidence
        let min_confidence = config
            .get("min_confidence")
            .and_then(|s| s.parse::<f32>().ok())
            .unwrap_or(0.7);

        Ok(specs.into_iter()
            .filter(|spec| spec.confidence >= min_confidence)
            .collect())
    }
}
```

```rust
impl UDAFModel {
    /// Construct U0 from projection universes via inverse mappings
    /// U0 = f₀₁⁻¹(U1) ∪ f₀₂⁻¹(U2) ∪ f₀₃⁻¹(U3)
    pub fn construct_u0(
        &mut self,
        graph: &SpecRepository,
        root: &RootSpace,  // NEW: explicit root
    ) -> Result<Vec<InferredSpecification>, String> {
        let mut newly_created_specs = Vec::new();

        for universe_id in self.universes.keys() {
            if universe_id.layer() == 0 { continue; }

            let inverse_transform_id = TransformId::inverse(universe_id);

            if let Some(transform) = self.transforms.get(&inverse_transform_id) {
                let extracted_specs = self.execute_transform(transform, graph, root)?;
                newly_created_specs.extend(extracted_specs);
            }
        }

        Ok(newly_created_specs)
    }
}
```
