# reviews

査読ログを用途別に整理したディレクトリです。

## Structure
- `by-reviewer/`
  - `reviewer1/rounds|strict|final|index`
  - `reviewer2/rounds|strict|final|index`
  - `reviewer3/rounds|strict|final|index`
- `professor/`
  - 教授ロール査読・指導ログ
- `summaries/`
  - `rounds/`: ラウンド要約
  - `final/`: 最終要約
  - `concerns/`: 懸念チェック
  - `milestones/`: 主要転換点のメモ

## Notes
- ファイル内容は変更せず、構造のみ再配置しています。
- 旧 `paper/reviews` 直下のファイル群はすべて上記配下へ移動済みです。
